## 2. 逐区深挖

### 2.1 会话侧边栏
- **工作区（Workspace）是独立概念**，不等于启动目录。默认工作区是 `~/Documents/deepseek-harness/default-workspace`；可以"添加工作区"选任意目录，会话指向该目录。
- 分组视图：按工作区分组 or 单列表；排序：手动 or 最近更新。
- 搜索：按标题/工作区名（内容级全文搜索需部署开关，默认名称匹配）。
- **会话层级视图**：展示会话与子代理的父子关系，子代理会话从树中展开——多 Agent 不再是黑盒。
- 归档（Archived sessions）管理旧会话。

> 对自研的改造点：我们要"会话制"，所以工作区不再出现在侧边栏第一层；工作区退化为**会话的可选属性**（挂载哪个目录、加载哪些规则），在会话设置里配置。

### 2.2 对话区
- 消息流渲染 Markdown；模型回复旁 👍/👎 反馈（可附说明）。
- **"本轮改动"摘要**：回答下方列出本会话改了哪些文件，点击看单个文件的 diff（+/- 行数）。实测一条会话显示 "Edited 5 files +678"。
- **分支（Branch）**：任意一条已完成消息下可以"在新对话中分支"——把该点之前的上下文复制为新会话，重述问题重试，不污染原线程。
- 重试：请求失败自动重试（带延迟与次数提示），也可手动。
- 输入框支持 `/compact` 等命令；Enter 行为可配置（排队发送 / 插话发送）。

### 2.3 轨迹视图（Trajectory）—— 你最看重的功能
- 对话页顶部 `[对话 | 轨迹]` Tab：
  - **对话**：人读的文本。
  - **轨迹**：模型看到的一切——逐条回放系统提示词、推理过程、每次工具调用的参数与返回、文件修改、终端命令。
- 数据源就是 session 事件流（JSONL），**按来源（source）过滤检查**：哪一步模型想错、哪个工具返回异常，一目了然。这是"黑匣子回放"，也是调 prompt、调工具 schema 的第一手材料。
- `/export` 把整段会话（含工具调用）打包 ZIP 下载。

> 自研可以直接复用：Trajectory UI = 消费 session event 流的只读渲染器，不需要任何额外存储。

### 2.4 运行统计条
- 输入框下方常驻：`turns / steps | LLM 耗时 · 工具耗时 | TTFT · tok/s | 缓存命中率 | 输入/输出 token`。
- 意义：让用户看见"Agent 的成本结构"——一个 15 行 Python 的一行修复 = 32.6K input（系统提示词+工具 schema 的固定开销），缓存吃掉 75%。**这个设计建议保留**，它是理解模型工作方式的教学工具。

### 2.5 任务状态与审批
- 四种内置 **Agent 预设**（决定新任务的工具与行为）：
  | 预设 | 能力 |
  |---|---|
  | Standard | 代码/文件/搜索/编辑/终端，通用 Agent 工作 |
  | PTC | Standard + 程序化工具调用（模型写代码一次组合多轮工具调用，省往返） |
  | Minimal | 只有持久 bash + 文件编辑工具，用于基准对比 |
  | Creator | Standard + 运行时检查、内存插件实验、自定义模式 |
- 审批弹窗：按 approval/policy（ask 等）对危险动作请求确认；预设 + 权限 preset（workspace-write 等）共同决定边界。

### 2.6 后台任务与工作流
- 长命令可后台跑（`sleep 10 &`、启动服务器），会话头部显示"N 个后台任务运行中"，点开看状态（运行中/已停止/已完成/已失败/已取消）与耗时，可停止。
- Workflow：把多步操作编排成独立节点在对话里执行（tool-workflow）。
- Automation：定时提醒与循环任务。
- 子代理任务（委派给 Codex/Claude Code 的）进 **Job Panel**：界面内直接看执行过程、状态、结果。

### 2.7 Settings 页
- **通用**：主题（浅/深/系统）、语言、繁忙时 Enter 行为、默认 Agent 预设、打开 settings.yaml。
- **模型**：
  - DeepSeek 官方：API Key、API 地址、Thinking 开关、推理等级、最大输出 token、上下文窗口、模型目录增删改 + "获取可用模型"。
  - 自定义提供方：Provider ID（建后不可改）、显示名、API 协议（三选一）、Base URL、Key、拉模型列表。
  - 删除提供方时提示是否连带删除存储的 Key。
- **插件**：开放配置的插件逐项可调（终端超时、并行工具调用数、网页搜索 Key 等），支持恢复默认。
- **Agent 预设**管理。

### 2.8 安全模型（Web/桌面）
- Web UI 默认只绑 `127.0.0.1:3080`，加一次性 token → cookie 两层防护；远程访问走 SSH 隧道而不是开 0.0.0.0——**这套默认安全姿态值得照抄**。
- 桌面版与 npm 版共用产品数据，包管理/激活状态/锁文件各自独立。

## 3. Workbench（工作环境层）的能力来源

dsh 的终端、文件管理是通过插件交付的（terminal、fs、lsp、browser-use、computer-use 等官方包）：

| 能力 | 实现来源 | 自研对应 |
|---|---|---|
| 内嵌终端 | terminal 插件 + PTY | 直接复用，装进桌面壳 |
| 文件树/文件预览 | fs 事件域 + web UI 组件 | 复用 + 按"双模式"调整挂载时机 |
| 代码编辑 | LSP 工具 + 编辑器组件 | 可先做只读+diff 视图，后接 Monaco |
| 浏览器 | browser-use 插件 | 复用 |
| Git | 未内置一等公民（Claude Code 有） | 自研补：Cline 的 Shadow Git 思路（隐藏 git 仓库逐步快照） |

## 4. 交互流程总结（一次典型任务）

1. 新建会话 → 选 Agent 预设 + 模型（或默认）。
2. 输入任务 → Runtime 组装 prompt/工具 → 流式回复，消息逐 token 出现。
3. 模型要执行动作 → 沙箱/审批 → 工具结果落日志 → 消息下方出现文件 diff 摘要。
4. 用户中途：Enter 插话（steering）、开分支重试、切模型、看轨迹回放。
5. 结束后：导出 ZIP / 👍👎 反馈 / 归档会话。

## 5. 自研 UI 需要增删的清单

**照抄**：三栏骨架、[对话|轨迹]双 Tab、本轮改动 diff 摘要、分支/重试/反馈、运行统计条、Settings 模型页（Key 只写不回显）、后台任务面板、会话层级树、loopback+token 安全默认。

**改造**：
1. 侧边栏第一层改为**会话列表**（ChatGPT 式），工作区挂载移入会话设置。
2. 默认新建会话**不扫盘、不加载项目规则**——AGENTS.md/CLAUDE.md/skill 改为显式挂载项。
3. 右侧增加**条件工作台面板**（Artifacts Studio）：仅当会话事件流出现 PPT/网页/文档任务信号时滑出，默认收起——见 05 号文档。
